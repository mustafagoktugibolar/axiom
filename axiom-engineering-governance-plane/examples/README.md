# Examples

These examples are intentionally concrete enough to seed an implementation.

- `governance/decisions/ARCH-042...` — accepted architecture decision.
- `governance/exceptions/EXC-023...` — scoped, expiring exception.
- `governance/designs/DESIGN-101...` — significant-change design.
- `repository/AGENTS.md` — portable lightweight bootstrap.
- `repository/.kiro/hooks/*` — Kiro lifecycle examples.
- `repository/azure-pipelines-governance.yml` — final CI gate concept.
- `repository/mcp-config.example.json` — illustrative MCP configuration.

Connector/harness configuration details can vary by product version; treat examples as patterns, not copied vendor defaults.
